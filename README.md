# Morocco Electricity Consumption and Environmental Factors Analysis

## 1. Project Overview

The Morocco Electricity Consumption and Environmental Factors Analysis project focuses on understanding electricity consumption patterns in Morocco and exploring the relationship between electricity usage and environmental factors such as temperature, humidity, and rainfall.

The project uses a structured project management approach to organise activities, manage tasks, identify risks, monitor progress, and document project outcomes.

## 2. Project Objectives

- Examine electricity consumption patterns in Morocco.
- Explore the relationship between electricity consumption and environmental factors.
- Identify and prepare relevant electricity and environmental datasets.
- Plan data analysis and machine learning activities.
- Document project progress, risks, challenges, and recommendations.

## 3. Tools and Technologies

| Tool | Purpose |
|---|---|
| Jira | Project planning, task management, sprint organisation, and progress monitoring |
| Confluence | Project documentation and reporting |
| GitHub | Project repository and documentation management |

## 4. Work Breakdown Structure

The project is divided into five major work packages:

1. **Project Initiation and Planning** – Define project objectives, scope, and requirements.
2. **Data Collection and Preparation** – Identify data sources, collect datasets, inspect, clean, and prepare data.
3. **Data Analysis** – Explore electricity consumption patterns and relationships with environmental factors.
4. **Machine Learning** – Plan model development, evaluation, and validation.
5. **Project Documentation and Closure** – Prepare reports, document findings, and close the project.

## 5. Project Management Activities

The following project management activities were completed:

- Developed a Project Charter.
- Created a Work Breakdown Structure (WBS).
- Established a Jira project backlog.
- Organised project tasks into two sprints.
- Assigned task priorities, estimates, start dates, and due dates.
- Developed a Project Risk Register.
- Monitored task progress using Jira.
- Simulated project delays and issue tracking.
- Prepared a Project Status Report.
- Prepared a Project Closure Report.

## 6. Identified Project Risks

The main risks identified include:

- Incomplete or unavailable electricity consumption data.
- Limited availability of reliable environmental data.
- Missing values, duplicate records, and inconsistent data formats.
- Delays in data preparation and analysis.
- Inaccurate or unreliable machine learning predictions.

## 7. Project Status

**Current Status: In Progress – Attention Required**

Project planning, documentation, and simulated monitoring activities were completed. Actual electricity consumption data analysis and machine learning model development were not completed as part of this project management exercise.
